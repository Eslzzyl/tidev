# TiDev - Hermes Agent 自进化能力分析

## 概述

本目录包含对 [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) 项目的自进化能力分析。项目已于 2026-04-18 克隆至 `hermes-agent/` 子模块。

## 核心发现

Hermes Agent 实现了 AI 编程助手的**自进化能力**，通过三大支柱实现：

1. **技能系统** - Agent 自主从经验中创建、编辑、优化和删除技能
2. **多层记忆架构** - 可插拔的外部记忆提供者 + 内置本地记忆
3. **智能上下文管理** - 保留上下文结构的同时压缩长对话
