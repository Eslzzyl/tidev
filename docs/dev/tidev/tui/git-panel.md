# Git 面板

Git 面板用于查看当前工作区的仓库状态、提交历史和差异。面板只执行查询
操作，不执行提交、暂存、切换分支或其他会修改仓库的 Git 操作。

## 入口

- 在 composer 中输入 `/git` 并提交。
- 使用面板启动器中的 `Git` 项。
- 使用 `F9` 快捷键。

## 视图

- `Status`：左侧显示文件状态和统计数量，右侧直接显示当前选中文件的工作区 diff。
- `History`：左侧显示提交列表，右侧直接显示当前选中提交的 diff；按 `j`/`k`
  选择提交，滚动到列表末尾会继续加载历史。

## 快捷键

数字 `1`、`2` 切换视图，Tab 和 Shift-Tab 循环切换视图，`r` 刷新，方向键或
`j`/`k` 选择，PageUp/PageDown 和鼠标滚轮滚动 diff，Esc 或 `q` 关闭面板。

## 数据流

`tidev-core::GitService` 以当前运行时 workspace 为工作目录，通过只读 Git
命令获取结构化状态、历史和 diff 数据。TUI 在独立的异步任务中执行查询，使用
请求 ID 丢弃过期结果，再由 `GitPanel` 完成渲染。Git 查询结果不会进入
`BackendEvent`，也不会修改会话消息、快照或发送给 LLM 的请求内容。

工作区 diff 同时补充未跟踪文件的内容；大于 10 MiB 的 diff 会被截断，并在
后端标记为 `truncated`。
